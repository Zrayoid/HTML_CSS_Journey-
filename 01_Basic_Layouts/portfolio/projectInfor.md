# Personal Portfolio Website

## About the Project

This is a personal portfolio website built using HTML and CSS.

The project introduces a fictional frontend developer, Alex Morgan, and displays their introduction, skills, navigation links, and contact buttons.

The main goal of this project was to practice creating a structured, responsive website while improving my understanding of HTML, CSS, and Flexbox.

## Technologies Used

- **HTML5** – Used to structure the website and organize its content.
- **CSS3** – Used to style the website, control layouts, and improve its appearance.
- **Flexbox** – Used to arrange elements and manage their alignment.
- **Media Queries** – Used to adjust the layout for smaller screens.
- **CSS `clamp()`** – Used to create flexible values that stay within minimum and maximum limits.
- **CSS `flex-wrap`** – Used to allow flex items to move onto another row when necessary.
- **CSS `aspect-ratio`** – Used to maintain the image's proportions.
- **CSS `object-fit`** – Used to control how the image fits inside its container.

## Project Features

- Navigation bar with links.
- Developer introduction section.
- Skills section.
- Profile image.
- Project and contact buttons.
- Footer with social media links.
- Responsive layout using Flexbox and media queries.
- Flexible typography and sizing using CSS.
